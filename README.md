🔒 LockedIn – Smart Productivity & Study Planner

Stay Focused. Stay Organized. Stay LockedIn.

LockedIn is a smart productivity and study-planning application developed using Flutter and Dart. It helps students organize their daily tasks, manage study time, maintain consistency, and track their productivity through a simple and user-friendly interface.

📌 Project Overview

Managing academic tasks, assignments, and study schedules can be challenging for students. LockedIn provides a centralized platform to manage daily activities, focus on important tasks, and monitor study progress.

The application aims to improve time management, productivity, and learning habits through useful planning and tracking features.

✨ Features

- Dashboard: View daily productivity and important information in one place.
- Task Management: Add, organize, and track daily tasks.
- Pomodoro Focus Timer: Improve concentration using focused study sessions and breaks.
- Daily Goals: Set and achieve daily study targets.
- Study Streaks: Maintain consistency by tracking study days.
- Weekly Statistics: Monitor productivity through weekly progress.
- Subject-wise Tracking: Organize and track study activities by subject.
- Dark & Light Mode: Switch between themes for a comfortable experience.

🚀 Getting Started

Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Git

Installation

1. Clone the repository

git clone https://github.com/24wh1a05ae/LockedIn.git

2. Navigate to the project folder

cd LockedIn

3. Install dependencies

flutter pub get

4. Run the application

flutter run

To run the application in Chrome:

flutter run -d chrome
